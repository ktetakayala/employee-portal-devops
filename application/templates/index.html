Automated CI/CD Pipeline for Employee Portal

A hands-on DevOps project demonstrating Infrastructure as Code, containerization, cloud infrastructure, automated testing, continuous integration and continuous deployment using Terraform, Docker, GitHub Actions, Amazon ECR and AWS EC2.

View Architecture Explore CI/CD Pipeline

About the Project

The Employee Portal project simulates a real-world DevOps environment where application changes pushed to GitHub are automatically tested, containerized, published to Amazon ECR and deployed to AWS EC2.

Infrastructure as Code

Terraform provisions and manages AWS EC2, Security Groups, IAM roles, Elastic IP, Amazon ECR and supporting infrastructure.

Containerization

The Flask application runs inside a Docker container and uses Gunicorn as the production WSGI server.

Continuous Integration

GitHub Actions installs dependencies and runs automated tests before allowing application deployment.

Continuous Deployment

Successful builds are pushed to Amazon ECR and automatically deployed to the EC2 Docker host.

Cloud Architecture

The project combines GitHub Actions, AWS IAM, Amazon ECR, EC2 and Docker into an automated deployment workflow.

Security Practices

Security controls are included in the infrastructure and deployment workflow.

GitHub OIDC

GitHub Actions obtains temporary AWS credentials instead of storing long-lived AWS access keys.

Least Privilege IAM

GitHub Actions and EC2 use separate IAM roles with limited permissions.

Restricted SSH

GitHub runner IP addresses are temporarily permitted on port 22 during deployment and removed afterward.

Non-Root Container

The application runs as a dedicated non-root user inside the Docker container.
